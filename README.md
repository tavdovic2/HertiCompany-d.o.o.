# Herti Company website

Product catalogue website for Herti Company d.o.o., https://herticompany.ba.

## Tech stack

Static HTML, CSS and vanilla JavaScript, generated by a dependency-free Node.js build script. No framework, no bundler.

## Project structure

```
src/
  data/        catalogue, company settings and SEO texts
  pages/       hand-written page content
  templates/   shared page fragments (layout, cards, page sections)
  assets/      CSS, browser JavaScript and images
  static/      files copied as-is (_headers, _redirects, robots.txt)
scripts/
  build.js     builds the site into dist/
  serve.js     local preview server
  lib/         build helpers
```

## Development

Requires Node.js 18 or newer.

```
npm run dev      # build and serve at http://localhost:8080
npm run build    # build into dist/
npm run clean    # remove dist/
```

## Deployment

Cloudflare Pages, connected to this repository: build command `npm run build`, output directory `dist`.

## Security

Security headers and a strict Content Security Policy (no inline scripts or styles) are set in `src/static/_headers`.
